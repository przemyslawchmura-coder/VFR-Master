# Research on Demand Wave 11: bounded source acquisition

User intent: advance demand-driven research beyond the repository-only Wave 10 seam without production, live Supabase, RLS, secrets, promotion or frozen 95-field/14-category changes. Execution is authorized autonomously; a live deployment remains separately authorized.

One layer only: canonical demand -> trusted exact source route -> existing asynchronous Factory acquisition -> content-addressed local custody -> SOURCE-ACQUIRED checkpoint. Acquisition cannot create reusable knowledge, review decisions or technical values. The job stops BLOCKED/EXTRACTION-REQUIRED, not COMPLETED or AWAITING_HUMAN_REVIEW: no candidate exists yet.

Routes bind validated ResearchTarget/SourceProspect, field IDs, operation, exact conditions, HTTPS URL, expected SHA-256 and byte budget. Canonical applicability comparison and existing readiness must pass before network I/O. Unknown context, unsupported fields, wrong catalogue, conditions or operation fail closed. Requests cannot provide URLs or provider metadata. An exact URL allow-list also blocks redirects before contacting another endpoint. Network failures reuse existing bounded retry classification; access failures remain blocked. Document identity mismatch never enters custody.

The initial route uses existing CBR500R PC70 MY2024 USA/Canada oil-specification lineage only. On 2026-10-05 the official PDF was reacquired, SHA-256 b04247cde951c92abc079c08d581d1b0553b9925156701d8d6087eff080405c9, 6911749 bytes. Cover p.1 identifies year/models; back cover p.184 carries both publication identifiers in the same document; p.19 and the repository's existing cbr500r-pc70-abs-applicability record establish ABS=true for this oil lineage. Publication relationship can therefore be SAME-UNDERLYING-PUBLICATION-PROVEN. Existing legacy target/prospect/report objects remain unchanged. The route retains the existing research model identity and standard-equipment scope; it does not add runtime identity aliases, field mappings or emissions applicability. Conditions are exactly requestContext.modelCode=PC70; other contexts stay unsupported. This route is not automatically wired to browser intake or deployed Edge worker.

Custody stores bytes outside tracked repository data, named by SHA-256, using exclusive create and verification on reuse. Checkpoints retain artifact identity, digest, byte count, source URL, source/prospect/publication identity and Factory/demand/job lineage; document body is excluded. Custody failure cannot report SOURCE-ACQUIRED. Existing duplicate-job claims must suppress repeat network work.

Proof: real Factory orchestration with HTTP responses under controlled test transport; success and duplicate claim, all applicability dimensions, condition/identity failures, wrong digest, redirects, HTTP access/retry failures, custody failure and corruption. A manual live public-HTTP proof may use only this official document, temporary local custody and local execution stores. No copyrighted PDF is committed.
