# CBR500R PC70 — wykonanie instrukcji obsługi

Istniejąca uwierzytelniona trasa instrukcji obsługi Honda 2024 została
wykonana raz dla dokładnie dwóch pól. PDF pozyskano przez ograniczoną ścieżkę
custody, a stronę 180 przetworzono istniejącym transformatorem `pypdf`.

- `lubrication.oil-specification`: jeden kandydat raw Tier A, zachowujący
  brzmienie API, SAE, JASO, oleju Honda i wyłączeń.
- `tires_wheels.loaded-pressures`: zatrzymane z powodem
  `NO_EXPLICIT_LOADED_CONDITION`. Instrukcja podaje standardowe ciśnienie
  CBR500R (wspólne dla tabeli `Except NX500`), ale nie oznacza go jako
  ciśnienie dla obciążenia/pasażera. Istniejącego pokrycia nie zdublowano.

Nie utworzono decyzji review, evidence ani promocji; nie zmieniono Service
Core, produkcji, katalogu, Supabase ani infrastruktury.
